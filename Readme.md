## Описание
Скрип за резюмиране на съдържанието на видеоклипове от YouTube написан на Python. 

Използва DeepSeek API за самостоятелно определяне на темите в клипа, прави кратко резюме и дава статистика на най-често използваните думи.

Резултата се извежда на конзола и се записва във файлове.

## Начин на използване

```sh
export DEEPSEEK_API_KEY="твоят_api_ключ"
python3 yt_analyzer.py "https://www.youtube.com/watch?v=xxxxxxxxx"
```

## Изисквания 

За нормална работа трябва да бъдат инсталирани следните библиотеки:

```sh
pip install yt-dlp stop-words requests
```
